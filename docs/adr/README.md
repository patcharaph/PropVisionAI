# Architecture Decision Records (ADR)

This directory contains Architecture Decision Records for PropVisionAI.

## What is an ADR?

An ADR is a short document that captures an important architectural decision made along with its context and consequences. We use the format proposed by [Michael Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).
